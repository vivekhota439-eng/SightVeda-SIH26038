HOW TO RUN ON ANY LAPTOP / PC:

Step 1: Extract (Unzip) this entire folder to your Desktop or preferred folder.

Step 2: Double-click 'run_website.bat'.
        The script will:
        - Automatically detect your current directory (works anywhere)
        - Check if Python is installed
        - Automatically install required packages (Flask, NumPy, OpenCV, SciPy, H5Py)
        - Start the server on http://127.0.0.1:5000
        - Automatically open your default web browser!

Step 3 (Manual Option if preferred):
        Open Command Prompt (CMD) in this folder and run:
        1. pip install -r requirements.txt
        2. python app.py
        3. Open your browser and go to: http://127.0.0.1:5000
